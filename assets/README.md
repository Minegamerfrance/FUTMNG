# FUTMNG Assets

Ce dossier servira de point d'entrée local pour les ressources FUTMNG :

- portraits / heads des joueurs ;
- visuels des cartes ;
- drapeaux ;
- logos de clubs ;
- visuels SBC / événements.

Les gros packs d'images pourront être distribués via les GitHub Releases afin de garder le dépôt principal léger.
